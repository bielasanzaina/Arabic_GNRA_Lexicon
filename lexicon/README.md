# AGG Lexicon

This directory contains the lexical resource used for the Aggregation (AGG) annotation described in the paper:

“Beyond Gender, Number, and Rationality: Modeling Extended Arabic Morpho-Syntactic Agreement with Aggregation.”

AGG labels:
- A = Atomic
- C = Collective
- G = Groupable
- D = Divisible

The lexicon is provided in [AGG lexicon.csv](AGG%20lexicon.csv).
